# Release notes - v0.3.0

Welcome to the first release notes of Katana. The project has supported my work in both personal and professional capacity, and with its recent adoption in ZubZet framework as its render engine. It provides me immense joy to know that it may have potential for wider adoption.

## What's new

Katana v0.3 release includes a minor bugfix, new features to customize runtime behaviour and, some quality of life improvements.

### Inline @php directive support

`@php .... @endphp` directive has been supported by Katana for a long time. However, it lacked was support for inline PHP directive when you needed to evaluate some expression.

```
@php($time = now())
```

### Use directive support

`@use` directive support eliminates, need for yet another `@php` block in your template files when you needed to import a specific class. It is one of the most interesting update in the lineup because of its backwards compatibility requirements.
[Video: How @use was implemented](https://youtu.be/4N-5L_VyUTI)
```
@use(Engine\Katana)

{{ Katana::VERSION }} -> 0.3.0
```

### Custom echo handlers

We have added little bit of magic and reflection under the hood; object based on concrete can be echoed directly using `{{ }}` and `{!! !!}` syntax via registered closures. Currently engine only supports closure based syntax and like Laravel blade intersection and union types are not supported.

```php
<?php
$blade->stringable(fn(DateTime $date) => $date->format("Y-F-d"));
```

```
{{ $date }} // Outputs using the registered closure
```

### Custom directive

Engine now support registering custom directives, allowing you to create domain specific directives, for richer and productive development experience.

```php
<?php
$blade->directive('wphead' fn() => "<?php wp_head(); ?>");
```

```blade
<head>
    ....
    @wphead
</head>
```

### Fixed: Default attribute merging

Default attributes using `{{ $attributes->merge(['x-data' => 'hello']) }}` prepended default values to the component attribute values after the update values are replaced except for the class attribute.
